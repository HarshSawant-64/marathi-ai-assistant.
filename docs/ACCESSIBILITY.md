# Accessibility

The prototype aims to be comfortable for first-time smartphone users and people with different vision, reading, and motor needs.

## Current support

- Marathi is the default language; Marathi, Hindi, and English can be chosen during onboarding and changed in Settings.
- Settings has larger-text and higher-contrast switches. Larger text increases app text by 25% and keeps OS font scaling enabled.
- High-contrast mode uses darker text on light surfaces and white text on dark surfaces.
- Primary actions, language rows, and the chat send button have large touch areas. The chat screen supports clearing the current conversation and cancelling its pending request.
- Input fields and controls have screen-reader labels or roles where applicable.
- Voice is not required; this build is text-only.

Accessibility features are not a substitute for usability sessions with older adults and people with disabilities.
