# Language support

| Code | Name shown in its script | Current support |
| --- | --- | --- |
| `mr-IN` | मराठी (Marathi) | Onboarding, UI strings, mock reply, localized scholarship source guidance; selected-language instruction for Gemini |
| `hi-IN` | हिन्दी (Hindi) | Onboarding, UI strings, mock reply, localized scholarship source guidance; selected-language instruction for Gemini |
| `en-IN` | English (India) | Onboarding, UI strings, mock reply, localized scholarship source guidance; selected-language instruction for Gemini |

All three options are selectable in the prototype. Mock replies are fixed examples. The scholarship source finder displays the same curated portal links in all three languages, with localized guidance. It does not translate or summarize portal content. Gemini is prompted to answer in the selected language, but Marathi, Hindi, English, and code-switching quality have not been evaluated with a live account. Speech recognition and synthesis are not implemented. Public-service guidance beyond those links is not yet curated or verified.
